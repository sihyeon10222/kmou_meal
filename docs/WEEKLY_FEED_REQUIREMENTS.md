# KMOU Weekly Feed Post — Consolidated Requirements

> 이 문서는 **주간 Instagram 피드 게시물 기능에 관한 확정 요구사항 전체**를 한 파일에 통합한 문서다.
---

## 1. 자동 업로드 일정

매주 **일요일 22:00 KST**에 다음 주 식단 게시물을 자동 업로드한다.

게시물은 총 3개:

```text
1. 교직원 식당
2. 학식(스낵코너)
3. 기숙사 식당
```

업로드 순서도 반드시 위 순서를 따른다.

```text
Teacher
→ Snack
→ Dormitory
```

모든 최종 게시물 이미지는 **3:4 비율**을 사용한다.

---

## 2. 기숙사 식당 게시물

### 형식

- 게시물 1개
- **2장 캐러셀**
- 대상: 다음 주 **월~일**
- 포함:
  - Breakfast
  - Lunch
  - Dinner

### 기본 배치

요일을 왼쪽→오른쪽으로 배치한다.

```text
월 | 화 | 수 | 목 | 금 | 토 | 일
```

각 요일 column 안에서는:

```text
Breakfast
Lunch
Dinner
```

을 세로로 구분한다.

### 파노라마 캐러셀

기숙사는 1장에 일주일치 아침/점심/저녁을 모두 넣으면 글자가 지나치게 작아지므로 **2장 파노라마 캐러셀**로 만든다.

두 이미지를 각각 따로 디자인하지 않는다.

먼저 **3:2 비율의 가로로 긴 마스터 이미지 1장**을 렌더링한 뒤, 정확히 가운데에서 잘라 **3:4 이미지 2장**으로 저장한다.

권장 기준:

```text
Master: 2160 × 1440
        ↓ x = 1080 기준 crop
Page 1: 1080 × 1440
Page 2: 1080 × 1440
```

7개 요일을 같은 폭으로 배치하면 중앙 crop 지점이 **목요일 column의 중앙**을 지나가게 된다.

따라서:

```text
[ 월 ][ 화 ][ 수 ][ 목
                      │
                      │  ← carousel 경계
                      │
                목 ][ 금 ][ 토 ][ 일 ]
```

형태가 되어, 첫 번째 이미지에서 잘린 목요일 영역이 두 번째 이미지에서 자연스럽게 이어지도록 한다.

중앙 crop 지점에는:

```text
별도 gutter
별도 page margin
페이지 구분용 여백
```

을 넣지 않는다.

목요일 배경/박스는 두 이미지 사이에서 자연스럽게 연결되어야 한다.

단, 중요한 메뉴 텍스트가 crop 선 한가운데에서 부자연스럽게 잘리지 않도록 실제 텍스트 배치는 적절히 조정한다.

---

## 3. 학식(스낵코너) 게시물

### 형식

- 게시물 1개
- 이미지 1장
- 대상: 다음 주 **월~금**

### 게시물에 포함

```text
분식코너
정식
```

### 게시물에서 제외

```text
양식코너
라면코너
```

양식코너와 라면코너는 매일 메뉴가 거의 비슷하므로 주간 게시물에는 넣지 않는다.

월~금을 왼쪽→오른쪽으로 배치한다.

```text
월 | 화 | 수 | 목 | 금
```

각 날짜 column 안에서 분식코너와 정식 메뉴를 세로로 구분한다.

---

## 4. 교직원 식당 게시물

### 형식

- 게시물 1개
- 이미지 1장
- 대상: 다음 주 **월~금**

월~금을 왼쪽→오른쪽으로 배치한다.

```text
월 | 화 | 수 | 목 | 금
```

각 날짜 column 안에서:

```text
Breakfast
Lunch
Dinner
```

을 세로로 구분한다.

---

## 5. 메뉴 없음 처리

특정 날짜/식사/코너에 메뉴가 없더라도 해당 영역을 제거하지 않는다.

해당 영역에는:

```text
메뉴 없음
```

을 표시한다.

---

## 6. 게시물 캡션

날짜 범위는 실제 대상 주차를 기준으로 자동 생성한다.

### 기숙사

예:

```text
2026년 9월 21일 ~ 9월 27일 기숙사 식단입니다.

#해양대학교 #해양대학생생활관
```

### 학식

예:

```text
2026년 9월 21일 ~ 9월 25일 학식 식단입니다.

#해양대학교 #해양대학식
```

### 교직원 식당

예:

```text
2026년 9월 21일 ~ 9월 25일 교직원 식당 식단입니다.

#해양대학교 #해양대교직원식당
```

게시물 종류에 맞는 해시태그만 붙인다.

---

## 7. 자동 실행 중복 방지

자동 실행에서는 동일한:

```text
주차 + 게시물 종류
```

조합이 이미 성공적으로 게시된 경우 다시 게시하지 않는다.

예:

```text
2026-W39 + teacher
2026-W39 + snack
2026-W39 + dormitory
```

이미 성공 기록이 있으면 자동 실행에서 skip한다.

게시 성공 기록은 실제 Instagram publish가 성공한 뒤 남긴다.

---

## 8. 수동 실행 / Preview / Force Publish

주간 게시물 전용 Manual/Preview workflow를 추가한다.

필요 기능:

```text
대상 주차 또는 base date 지정

게시물 종류 선택
- Teacher
- Snack
- Dormitory
- All

Preview only
Force publish
```

### Preview

Preview에서는 Instagram에 게시하지 않고 생성된 이미지를 artifact 등으로 확인할 수 있게 한다.

### Force Publish

수동 실행은 기본적으로 중복 방지를 적용하되:

```text
force publish
```

옵션을 켜면 동일 주차/동일 종류 게시물도 다시 게시할 수 있게 한다.

---

## 9. 일요일 22:00 전체 실행 순서

일요일 22:00에는 **주간 피드 게시물 작업을 먼저 전부 끝낸 뒤** 기존 22:00 Story batch를 실행한다.

정상 실행 순서:

```text
1. Teacher weekly post
2. Snack weekly post
3. Dormitory weekly carousel post
4. 기존 22:00 tomorrow_full_batch Story
```

즉:

```text
Feed Posts
→
Stories
```

순서를 반드시 보장한다.

Story batch는 필요한 주간 게시물 3개가 모두 완료된 뒤에 시작한다.

여기서 완료는:

```text
새로 정상 게시됨
또는
이미 같은 주차 게시물이 성공적으로 올라가 있어 중복 방지로 정상 skip됨
```

을 의미한다.

필수 주간 게시물 중 하나라도 게시 실패 상태라면 그 실행에서는 Story 단계로 넘어가지 않는다.

---

## 10. 구현 방향

기존 Story 자동화는 유지하고, 별도의 **Weekly Feed Post** 흐름을 추가한다.

필요한 흐름:

```text
다음 주 날짜 범위 계산
→ 여러 날짜의 식단 조회
→ 게시물용 이미지 렌더링
→ 기숙사 3:2 panorama master 생성
→ 기숙사 master를 3:4 두 장으로 crop
→ Teacher 게시
→ Snack 게시
→ Dormitory carousel 게시
→ 모두 완료 확인
→ 기존 22:00 Story batch 실행
```

세부적인:

```text
파일 구조
mode 이름
renderer 구조
Instagram feed publisher 구조
중복 기록 저장 방식
workflow input 구조
```

는 현재 코드에 맞춰 가장 자연스럽고 유지보수하기 좋은 방식으로 정한다.

---

## 11. 작업 지시 요약

```text
기존 Story 자동화는 유지하고 Weekly Feed Post 기능을 추가해.

매주 일요일 22:00 KST에 다음 주 식단 게시물을 아래 순서로 업로드해:
1. Teacher
2. Snack
3. Dormitory

Teacher:
- 월~금
- Breakfast/Lunch/Dinner
- 3:4 단일 이미지

Snack:
- 월~금
- 분식코너/정식만
- 양식코너/라면코너 제외
- 3:4 단일 이미지

Dormitory:
- 월~일
- Breakfast/Lunch/Dinner
- 3:2 master(예: 2160×1440)를 먼저 렌더링
- 가운데에서 잘라 3:4 이미지 2장으로 저장
- 목요일이 양쪽 이미지에 걸쳐 자연스럽게 이어지는 panorama carousel

메뉴가 없으면 해당 영역에 `메뉴 없음`.

캡션은 실제 대상 날짜 범위를 자동 생성하고 게시물 종류에 맞는 해시태그를 사용해.

자동 실행에서는 동일 주차+게시물 종류 중복 게시를 막고,
Manual workflow에서는 Preview와 Force Publish를 지원해.

주간 게시물 3개가 모두 완료된 뒤에만 기존 22:00 Story batch를 실행해.
구현 세부사항은 현재 코드와 기존 디자인 시스템을 보고 가장 적절하게 결정해.
```
