# 현재 주간 피드 정책

현재 구현과 운영 문서의 기준을 요약합니다. 이전 [통합 요구사항](../archive/WEEKLY_FEED_REQUIREMENTS.md)은 과거 기록입니다.

- 한국시간 매일 18시에 대상 주차를 확인합니다. 월~토는 해당 주, 일요일은 다음 주입니다. 외부 예약이 workflow를 호출합니다.
- 처리 순서는 `combined`(학식·교직원식당), `badaro`(승선생활관), `dormitory`(기숙사)입니다. 한 종류의 실패가 다음 종류를 막지 않습니다. Story와 피드는 독립 실행입니다.
- 학식은 월~금 양식·라면·분식·정식 네 코너, 교직원식당은 월~금 세 끼를 각각 한 이미지로 구성해 통합 게시합니다. 한 식당 전체가 비면 그 식당 이미지를 제외합니다.
- 두 생활관은 각각 월~일 세 끼를 2160×1440 마스터에 배치하고 1080×1440 두 장으로 나눕니다. 목요일 글자가 중앙에서 나뉘는 것은 의도된 파노라마입니다.
- 메뉴 글자는 끼니·학식 코너 행마다 18~30px의 최대 두 단계로 배분합니다. 요일별 가로·세로 최대 크기를 측정한 뒤 축소량 합계가 가장 작은 조합을 선택하며, 두 단계는 최소 3px 차이를 둡니다. 동률이면 작은 모드의 요일 수가 적은 조합, 그다음 일반 크기가 큰 조합을 우선합니다. 같은 요일·끼니 안의 메뉴는 동일 크기이며 빈 식단 안내는 별도 크기를 유지합니다.
- 최초 자동 게시와 자동 재게시에는 한국시간 내일 이후의 빈 끼니에 메뉴가 생겨야 합니다. 학식은 코너별로 판정합니다. 수정·삭제 또는 오늘까지의 추가만으로는 자동 재게시하지 않습니다.
- 재게시 이미지와 성공 snapshot은 주간 전체의 최신 조회 결과를 반영합니다. 비교 원본이 있으면 날짜와 무관하게 추가·수정된 메뉴만 `var(--changed)`로 강조합니다. 최초 게시에는 강조하지 않습니다.
- 주차·종류별 성공 기록과 원자적 잠금으로 중복을 방지합니다. 게시 결과가 불확실하면 잠금을 유지하며 수동 확인이 필요합니다.
- `--force`는 수동 재게시를 허용합니다. 기존 게시물은 직접 삭제하고, GitHub 교체 알림은 실패 시 다음 실행에서 재시도합니다.
- 상세 캡션·레이아웃·재시도 계약은 [게시 정책](../operations/publishing.md)을 따릅니다.
