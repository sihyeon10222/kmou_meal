# 해양이

`haeyangi.png`는 사용자가 제공한 `KMOUAI/해양이캐릭터.png` 원본입니다.
캐릭터는 생성형 AI 입력으로 전송하지 않고 투명 여백 제거·비율 유지 리사이즈·합성에만 사용합니다.
음식과 말풍선만 Cloudflare Workers AI에서 생성합니다.

`food-bubble-reference.png`는 사용자가 추가로 제공한 점심 말풍선 예시를 최대 448px로 축소한 디자인 참고 이미지입니다. 생성 시에는 프롬프트로 이 구성을 설명하며 파일을 전송하지 않습니다. 각 생성 결과는 말풍선 하나 안에 Lunch/Dinner 제목·해/달·음식을 모두 포함합니다.
